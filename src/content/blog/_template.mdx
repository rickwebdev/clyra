## First Major Section

Body copy. Use `##` for main sections and `###` for subsections.

### Subsection

- Bullet points work as expected
- **Bold** and *italic* formatting
- [Links](https://example.com) to external resources

### Checklist blocks (bold header + sub-bullets)

- **First item title** with optional trailing text
  - Supporting detail one
  - Supporting detail two
- **Second item title**
  - Supporting detail

These render as alternating gradient cards automatically.

## Second Major Section

More content. Common patterns in existing posts:

1. Numbered lists for step-by-step guides
2. Checklists using `- [ ]` syntax
3. Code blocks for technical snippets:

```bash
wp plugin install wordfence --activate
```

## Tables

Leave a blank line before the table. Use pipe syntax — one row per line:

| Column A | Column B |
|---|---|
| Row 1 | Value |
| Row 2 | Value |

Wide tables scroll horizontally on mobile automatically.
